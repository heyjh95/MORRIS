# MORIS 웹사이트

한국어·영어로 제공하는 정적 웹사이트입니다. 문구와 이미지는 HTML에서 직접 수정합니다.

## 먼저 수정할 파일

| 바꿀 내용 | 파일 |
| --- | --- |
| 한국어 문구·이미지·링크 | `html/index.html` |
| 영어 문구·이미지·링크 | `html/en.html` |
| 슬라이드·선택 버튼·메뉴 동작 | `js/main.js` |
| 공통 컨테이너·제목·버튼 | `scss/_common.scss` |
| 색·화면 크기 기준·겹침 순서 | `scss/_vars.scss` |
| 영역별 스타일 | `scss/_header.scss`, `_hero.scss`, `_new-products.scss` 등 |

HTML의 `<!-- 신제품 -->`, `<!-- 제품 카테고리 -->` 같은 주석으로 수정할 영역을 찾습니다. 저장하고 브라우저를 새로고침하면 됩니다.

미정 목적지는 `<a href="#">`로 작성합니다. 실제 섹션 이동과 언어 전환 링크는 해당 주소를 사용합니다.

## CSS 빌드와 확인

Node.js 22 이상을 사용합니다.

```bash
npm ci
npm run build
npm test
```

SCSS를 수정했을 때만 CSS를 다시 빌드합니다. `scss/layout.scss`가 진입점이고, `css/layout.css`와 `css/layout.min.css`를 만듭니다. HTML은 압축 CSS를 읽습니다. CSS 파일을 직접 고치면 다음 빌드에서 덮어씁니다.

웹 서버에서 루트 `index.html`을 열면 한국어 페이지로 이동합니다. HTML 생성 과정은 없습니다.

## 동작과 스타일을 읽는 순서

1. HTML에서 원하는 영역을 찾습니다.
2. `js/main.js`에서 해당 영역의 `init…Slider()`를 읽습니다. 메인·신제품·카테고리·브랜드는 모두 Swiper를 사용합니다.
3. 여러 영역의 기본 모양은 `scss/_common.scss`, 해당 영역의 차이는 영역별 SCSS에서 찾습니다.

버튼의 `aria-controls`와 패널의 `id`가 같으면 서로 연결됩니다. 카테고리나 브랜드를 추가할 때는 버튼과 패널을 한 쌍으로 복사하고 고유 ID를 붙입니다. 한국어·영어 페이지에 같은 ID를 사용합니다.

두 언어 페이지와 가로 메뉴·전체 메뉴의 HTML은 각각 직접 관리합니다. 메뉴·섹션을 변경하면 대응하는 부분도 함께 고칩니다. 테스트는 두 메뉴의 일치, 두 언어의 ID·이미지 구성, 버튼과 패널 연결, 파일 경로를 검사합니다. CI는 CSS 빌드 결과도 검사합니다.
